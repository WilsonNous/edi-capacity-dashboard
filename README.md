# EDI — Painel de Capacidade e Atendimento

## Executar no PyCharm / terminal

Use o ambiente virtual do projeto e execute:

```bat
python -m streamlit run app.py
```

## Arquivo de dados

Carregue o CSV exportado do Redmine pela barra lateral.

Também é possível deixar um arquivo `issues.csv` no mesmo diretório do `app.py`.

## Aparência

A interface utiliza uma paleta inspirada no Facebook/Meta:
- Azul principal: #1877F2
- Fundo: #F0F2F5
- Cartões: #FFFFFF
- Texto: #1C1E21

O arquivo `.streamlit/config.toml` deixa a barra do Streamlit em modo mínimo.
