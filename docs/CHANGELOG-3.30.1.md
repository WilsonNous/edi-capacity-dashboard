# EDNNA v3.30.1

- Follow-up passa a herdar o modo operacional da regra.
- Regras AUTOMÁTICAS (incluindo SIM REDE no catálogo operacional) têm follow-up executado pelo worker.
- Regras ASSISTIDAS continuam com edição e botão manual na Operação de hoje.
- Worker não envia mais follow-up de regra assistida automaticamente.
- Operação de hoje não oferece botão para follow-up automático.
- Problemas de identificação passam a contar somente ambiguidade real de player/origem.
- Regras não homologadas deixam de inflar o indicador de identificação.
- A lista de problemas de identificação mostra chamado, cliente, candidatos e o que falta.
