# EDI Capacity Dashboard — v3.12.0 Observatório de Automações

A aba **Demandas e automação** agora inclui ranking de prontidão, distribuição por intenção, clientes/origens recorrentes, chamados candidatos e exportação CSV por intenção.

O índice de prontidão combina volume, confiança média e presença de regra candidata. É somente um indicador de priorização e **não autoriza execução**.

A versão continua em modo OBSERVAÇÃO: nenhuma regra envia e-mail, altera status, comenta no Redmine ou executa scripts.
